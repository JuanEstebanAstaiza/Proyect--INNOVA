¿Qué es SMTP?

SMTP (Simple Mail Transfer Protocol) es el protocolo estándar para envío de correos electrónicos. Cada municipio puede tener su propia configuración de correo electrónico.

Configuración necesaria
  • Servidor SMTP (ej: smtp.gmail.com)
  • Puerto (generalmente 587 para TLS, 465 para SSL)
  • Usuario y contraseña del correo
  • Correo y nombre del remitente
