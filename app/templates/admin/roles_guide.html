Guía de Roles y Permisos

Aprende a gestionar roles y permisos de manera efectiva

Volver a Roles
¿Qué es el Sistema de Roles?

El sistema de roles permite controlar de manera granular qué usuarios pueden hacer en el sistema. Cada rol tiene permisos específicos sobre las columnas de la tabla Excel, permitiendo que diferentes usuarios puedan editar diferentes aspectos del plan de desarrollo.

Tip: Un usuario puede tener múltiples roles asignados, y sus permisos serán la combinación de todos los roles que tenga.
Roles por Defecto del Sistema
Administrador

Acceso completo al sistema. Puede gestionar usuarios, roles y editar todos los planes.

Sistema Todos los permisos
Permisos:
  • Gestionar usuarios
  • Crear/editar roles
  • Editar todas las columnas
  • Ver todos los datos
  • Permisos de fila ilimitados
Editor General

Puede editar planes de desarrollo pero no gestionar usuarios o roles.

Sistema Edición limitada
Permisos:
  • Editar códigos de línea
  • Editar componentes
  • Editar programas y proyectos
  • Editar metas e indicadores
  • No gestionar usuarios
  • No crear roles
Editor de Ejecución

Puede editar datos de ejecución trimestral y porcentajes de cumplimiento.

Personalizado Ejecución
Permisos:
  • Editar ejecución trimestral
  • Editar % cumplimiento
  • Editar población impactada
  • Editar observaciones
  • No editar estructura
  • No editar metas
Editor de Metas

Puede editar metas, indicadores y datos básicos del plan.

Personalizado Metas
Permisos:
  • Editar metas
  • Editar indicadores
  • Editar línea base
  • Editar tipos y unidades
  • Editar sentido
  • No editar ejecución
Visualizador

Solo puede ver información del plan de desarrollo.

Sistema Solo lectura
Permisos:
  • Ver todas las columnas
  • No editar nada
  • No gestionar usuarios
  • No crear roles
  • No permisos de fila
Crear Roles Personalizados
Pasos para crear un rol personalizado:
  1. Accede a "Crear Rol": Ve al panel de administración → Gestión de Roles → Crear Rol
  2. Información básica: Define nombre, descripción y color distintivo
  3. Configura permisos: Selecciona qué columnas puede ver y editar el rol
  4. Organización por categorías: Las columnas están organizadas en categorías:
    • Estructura: Códigos, líneas estratégicas, componentes, programas
    • Indicadores: Metas, indicadores, tipos, unidades, línea base
    • Ejecución: Datos trimestrales de ejecución
    • Cumplimiento: Porcentajes de cumplimiento
    • Población: Datos de población impactada
    • Observaciones: Comentarios y notas
  5. Guardar: El rol se crea con los permisos especificados
Importante: Los roles del sistema (Administrador, Editor General, Visualizador) no pueden ser eliminados y tienen permisos predefinidos que no se pueden modificar.
Ejemplos de Roles Personalizados
  • Editor de Componentes
  • Supervisor de Programas
  • Analista de Metas
  • Reportador de Ejecución
  • Auditor Externo
Asignación de Roles a Usuarios
Cómo asignar roles a los usuarios:
  1. Accede a "Asignación de Roles": Panel Admin → Asignación de Roles
  2. Selecciona usuario: Busca al usuario por nombre o usuario
  3. Asigna rol: Haz clic en "Asignar Rol" en la tarjeta del usuario
  4. Selecciona rol: Elige el rol apropiado del listado
  5. Agrega notas: Opcionalmente explica por qué se asigna este rol
  6. Confirma: El rol queda asignado y activo inmediatamente
Nota: Un usuario puede tener múltiples roles asignados simultáneamente. Sus permisos serán la combinación de todos los roles que tenga.
Asignaciones Múltiples

Un usuario puede tener varios roles para combinar permisos específicos.

Ejemplo:
Usuario con roles:
• Editor de Metas
• Editor de Ejecución

Resultado: Puede editar tanto metas como datos de ejecución.
Permisos Específicos de Fila
¿Qué son los permisos de fila?

Los permisos de fila permiten que un usuario pueda editar filas específicas aunque no tenga permisos generales para esa columna. Esto es útil cuando un usuario especializado necesita editar solo ciertos indicadores o proyectos.

Cómo asignar permisos de fila:
  1. Accede a "Permisos de Fila": Panel Admin → Permisos de Fila
  2. Busca indicador: Busca el indicador específico que quieres permitir editar
  3. Selecciona usuario: Elige al usuario que podrá editar esta fila
  4. Asigna permiso: Confirma la asignación con notas opcionales
  5. Verificación: El usuario podrá editar solo esa fila específica
Beneficio: Permite delegar responsabilidades específicas sin dar acceso general a toda una columna.
Casos de Uso
  • Supervisor de proyecto específico
  • Especialista en indicador particular
  • Responsable de componente específico
  • Auditor externo limitado
Mejores Prácticas
Principios Generales
  • Principio de menor privilegio: Otorga solo los permisos necesarios
  • Separación de responsabilidades: Diferentes roles para diferentes tareas
  • Documentación clara: Describe claramente qué hace cada rol
  • Revisiones periódicas: Revisa y actualiza permisos regularmente
Recomendaciones
  • Nombres descriptivos: Usa nombres que indiquen claramente el alcance
  • Colores distintivos: Asigna colores únicos a cada rol
  • Notas de asignación: Documenta por qué se asigna cada rol
  • Permisos específicos: Prefiere permisos específicos sobre generales
Consideraciones de Seguridad
  • No asignes Administrador a usuarios que no necesiten gestionar el sistema
  • Revisa permisos antes de asignar roles nuevos
  • Documenta cambios en permisos para auditoría
  • Monitorea actividad de usuarios con permisos elevados
  • Remueve permisos de usuarios que ya no los necesiten
